# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, available in
full at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
(and in [many translations](https://www.contributor-covenant.org/translations/)).

In short: everyone taking part in this project — issues, pull requests,
discussions, reviews — is expected to behave respectfully. Harassment,
personal attacks, and discriminatory language are not tolerated, and neither is
publishing someone else's private information.

Technical disagreement is welcome and expected. Aim it at the code.

## Reporting

Report unacceptable behaviour privately to the maintainers, through the contact
listed on the repository owner's GitHub profile, or via the repository's
**Security** tab → **Report a vulnerability** if you need a confidential thread
and have no other channel.

Reports are handled privately. Maintainers will not name a reporter without
their consent, and may remove content, or block accounts, in response to
behaviour that violates this document.
